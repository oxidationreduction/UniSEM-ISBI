This page presents the UniSEM research project. Its existence does not imply acceptance or an official conference endorsement. Publication-ready source code, model artifacts, manuscript figures, and dataset-derived samples have separate provenance and availability.

Software and scientific dependencies

  • Segment Anything for Microscopy (µSAM): the prompt-free dense prediction interface and related implementation foundations. Upstream software uses the MIT License.
  • HQ-SAM: cross-layer feature fusion and a high-quality correction branch motivate the task-specific dense correction in UniSEM. Upstream software uses Apache-2.0.
  • Segment Anything supplies the encoder foundation; LoRA supplies low-rank adaptation. Consult the source release’s third-party notices for copied or adapted code and their terms.

Website design references

EM sample images

The twelve viewer images are byte-for-byte copies of the frozen manuscript crops from WaferEM. The viewer does not change segmentation labels or compute new scores. Raw images retain their documented display intensity range. Prediction colors are matched by maximum full-slice ground-truth overlap, while actual prediction boundaries are retained.

Dataset terms: dataset terms remain applicable to the raw images, ground truth, and derived examples. The source-code license does not relicense these data or grant redistribution permission. Obtain the dataset through its official source and review its terms. The EMNeuron dataset source has its own dataset card and provenance.

The GIF is a display-only wipe generated from the same existing crops. It contains neither generated microscopy imagery nor new model inference. The current viewer follows seed 12345 on the documented WaferEM test volume. Whole-slice metrics are labeled separately from the displayed region.

Dataset attribution and display changes. WaferEM samples: cyd0806/wafer_EM, distributed via Hugging Face. The public dataset listing identifies CC BY-NC 4.0. These non-commercial research visualizations use documented XY mean-downsampling of raw images, stride-2 label sampling, fixed crops, and pseudocolor instance rendering; actual prediction boundaries are preserved. The GIF animates comparisons of existing predictions. Data-derived assets retain dataset terms and are excluded from the software and website-code licenses. Full data access may require accepting provider conditions; no model-weight redistribution permission is inferred.
