# Reproducibility and version identity

This release follows the current two-stage ISBI study, not the earlier
decoder/HQ-only LightFT scaffold. `configs/paper_protocol.json` is the
machine-readable protocol. Website numbers are frozen reported results;
they are not generated by a browser benchmark.

## Separate the neural and graph models

The reported EMNeuron pipeline pairs the original first-stage neural export
with the July 24 full55 RF and equal weighting of eight test volumes. The
June RF belongs to a different historical result. Current target LightFT and
FullFT each use their own final RF.

The representative target model uses seed 12345, matching the existing display
cache. Three-seed means cannot be reproduced by evaluating that checkpoint
alone. All target seed identities are in `models/seed-identities.json`.

## Evaluation exposure

The current test split was fixed for the reported comparisons. The dataset
also had historical development use; this release does not claim the test
volume was accessed only once. Target selection uses training-monitor crops
inside the label budget and can overlap training. It is not independent
validation. Source selection uses separate source validation volumes.

## Display identity

The current viewer uses two existing crops from seed 12345 at fixed locations.
Typical improvement and residual error were selected using a recorded
whole-slice comparison and a disagreement-based crop. Colors correspond
through GT overlap while preserving actual instance boundaries. Display
images and metric arrays are different artifacts.

The historical gallery retains the original AAAI image's head-only LightFT
and TokenUnify-1B identities. It does not relabel them as current all-layer
LightFT or TokenUnify-500M.

## Release preparation

Source code and candidate models are separate deliverables. The source
package excludes original training data, private storage paths, and optimizer
states. Original-source and sanitized-file hashes are recorded separately.
Neural payloads contain tensors and public configuration; RFs retain their
original trusted joblib representation and exact hashes.

Display crops accompany the manuscript; candidate model files remain local.
Asset permissions remain separate from code licensing. No public weight URL,
DOI, or conference acceptance is asserted.
